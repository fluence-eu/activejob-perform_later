# activejob-perform_later

Run any method of any class, module or instance in the background through
Active Job — no dedicated job class needed.

```ruby
Report.perform_later.compute("2026-06")
Report.perform_later(queue: :low, wait: 10.minutes).compute("2026-06")
invoice.perform_later.generate_pdf          # instances via GlobalID
Maintenance.perform_later.purge             # modules too
```

The direct call (`Report.compute(...)`) stays synchronous and untouched.
Options are passed straight to `ActiveJob::Base.set` (`queue:`, `wait:`,
`wait_until:`, `priority:`).

## Per-class and per-method job configuration

`perform_later` calls go through a generic job by default. Declare a dedicated
job to use the full Active Job class DSL — `retry_on`, `discard_on`,
`rescue_from`, `queue_as`, callbacks, and adapter extensions such as
`limits_concurrency` (Solid Queue):

```ruby
class Report
  perform_later_job do                      # applies to the whole class
    queue_as :reports
    retry_on Timeout::Error, attempts: 5
  end

  perform_later_job :compute do             # applies to one method only
    limits_concurrency to: 1, key: ->(target, *) { target }
    discard_on ActiveRecord::RecordNotFound
  end

  def self.compute(month)
    # ...
  end
end
```

Job resolution order: method job (`Report::ComputePerformLaterJob`) → class
job (`Report::PerformLaterJob`) → generic (`ActiveJob::PerformLater::Job`).
Method jobs inherit the class job, so rules cumulate.

When a class method and an instance method share a name, scope the job:

```ruby
perform_later_job :sync, on: :class do ... end      # Report.perform_later.sync
perform_later_job :sync, on: :instance do ... end   # report.perform_later.sync
```

## Configuration

```ruby
ActiveJob::PerformLater.base_job = "ApplicationJob"  # default: "ActiveJob::Base"
```

Parent class of the jobs generated by `perform_later_job`.

## Error behavior

- Unknown or private method → `NoMethodError` at enqueue time, not in the worker.
- Non-serializable instance (no GlobalID, no custom serializer) →
  `ActiveJob::SerializationError` at enqueue time.
- Target class removed before the job runs → `NameError` at perform.

## Requirements

Ruby >= 3.2, activejob >= 7.1.
